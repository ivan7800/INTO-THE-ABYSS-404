# Auditoría y pruebas reproducibles — REBIRTH v0.60

**Fecha:** 29 de octubre de 2026.

## Funcionalidad implementada

- `INICIAR-WINDOWS.bat` + `launch-windows.ps1`: servidor local con PowerShell, sin Python/Node ni elevación UAC.
- `INICIAR-LINUX.sh` + `launch-local.py` / `launch-local.cjs`: servidor local y apertura del navegador.
- Origen fijo `http://127.0.0.1:8765/`, comprobación de instancia ya existente; aborta si otro servicio ocupa ese puerto.
- Cursor táctico isométrico por teclado, inspección de loseta con ratón/flechas y acciones con Enter.
- Confirmación antes de borrar el progreso mediante REINICIAR CAMPAÑA.
- Conserva la campaña, las reglas, las partidas y el adaptador PixiJS opcional.

## Pruebas ejecutadas

```bash
npm run build
npm test
node qa-v060.cjs
python3 qa-launchers.py
python3 qa-v060-browser.py
```

- **PASS** compilación de TypeScript y pruebas heredadas, incluidos cinco sectores y jefe final.
- **PASS** comprobaciones estáticas de los dos lanzadores, puerto fijo, bucle local y controles de teclado.
- **PASS** arranque real de `INICIAR-LINUX.sh` (Python 3), respuesta HTTP, página y recursos, bloqueo de rutas de escape, segundo arranque sobre instancia existente.
- **PASS** implementación alternativa Node.js, con las mismas comprobaciones HTTP.
- **PASS** Chromium headless: K, flechas, inspector, movimiento real con Enter, avance de turno, exportación de partida y reinicio cancelado sin pérdida de estado.
- **PASS** ninguna excepción JavaScript durante la prueba específica v0.60.

## No verificado (no se afirma PASS)

- Ejecución del BAT/PowerShell en **Windows real** (sin Windows ni PowerShell instalados en esta máquina).
- PixiJS 8 real (biblioteca no empaquetada; no accesible desde npm/CDN en este entorno).
- Compositor WebGL2 sobre una **GPU física** (Chromium de estas pruebas usa la alternativa Canvas 2D).
- Rendimiento estable 60 FPS en hardware final, accesibilidad con lector de pantalla, balance competitivo y pruebas largas de campaña por usuarios humanos.
