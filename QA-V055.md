- `pixi.js@8.19.0` **no está incluido** en este ZIP: npm y los CDN son inaccesibles en el entorno de generación. El código del adaptador sí está incluido, pero no existe prueba de ejecución con la librería real.
- Chromium aquí informó `webgl2-unavailable` y utilizó Canvas 2D; no hay evidencia de WebGL2/Pixi real sobre una GPU.
- Lanzador Windows nativo, FPS en equipos destino, sesiones manuales de balance y accesibilidad humana no probados.

## Compatibilidad
- `SAVE_KEY='into-the-abyss.v0.8.save'` se mantiene, sin cambios de esquema.
- Origen fijo: `http://127.0.0.1:8765/`. Versiones muy antiguas que usaban puertos aleatorios requieren exportar la partida desde su origen antiguo.
- No hay telemetría ni backend; los scripts de juego no realizan peticiones externas. Si el bundle local Pixi no existe se mantiene el fallback.

## Cómo verificar PixiJS auténtico al tener conexión

```bash
npm install
npm run vendor:pixi
npm run build
bash INICIAR-LINUX.sh
```

La barra inferior debe indicar **PIXIJS 8 · WEBGL**. Además, desde las herramientas de desarrollador comprueba `window.AbyssPixi.status` (debe ser `active`) y que `window.AbyssPixi.frames` incrementa. La siguiente entrega deberá verificar visualmente este estado con librería real y GPU compatible.
