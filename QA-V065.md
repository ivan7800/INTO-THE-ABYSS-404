# Auditoría reproducible — REBIRTH v0.65

## Compilación y regresiones

| Test | Comando | Resultado |
|---|---|---|
| TypeScript y bundle del juego | `npm run build` | PASS |
| Regresiones antiguas y tests v0.65 | `npm test` | PASS |
| Lanzadores Linux Python/Node + HTTP local | `python3 qa-launchers.py` | PASS |
| Chromium: clima/panoramas/campaña | `python3 qa-v065-browser.py` | PASS |

## Observaciones de Chromium

- Cinco panoramas diferentes comprobados mediante las huellas SHA-256 de sus datos PNG generados en navegador.
- Sin errores JavaScript detectados (`pageerror`).
- Mover cursor con teclado, exportar guardado JSON y finalizar turno funcionaron.
- Los efectos visuales son independientes del estado del juego (comparación antes/después de dibujar cinco escenarios).
- Renderizador usado: **Canvas 2D**; en este entorno Chromium no ofrece WebGL2 verificable.

## Límites importantes

- El adaptador PixiJS se compila, pero **no se ha probado con la biblioteca real**, que no está incluida.
- El lanzador BAT/PowerShell no se ha probado sobre Windows 10/11 real.
- La prueba de navegador valida funcionalidad, no una evaluación artística humana ni rendimiento en tarjetas gráficas físicas.
- La campaña y simulaciones de regresión pasan, pero eso no garantiza que el balance sea excelente.

## Inspección manual recomendada

1. Abrir v0.65 en cada plataforma, comprobar que los dos lanzadores realmente muestran juego.
2. Probar selección, movimiento, ataque y fin de turno, con turnos posteriores.
3. Revisar los cinco sectores reales de campaña; que el contraste de amenazas sea legible con clima.
4. Comprobar las dos opciones de calidad gráfica y `prefers-reduced-motion`.
5. Exportar partida, cerrar servidor, iniciar de nuevo e importar copia JSON.
